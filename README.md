# Monochrome 3D redesign

Replace these files in `frontend/`:
- `src/App.jsx`
- `src/index.css`
- `tailwind.config.js`

Keep your existing:
- `src/data/projects.json`
- `src/data/cvData.js`
- `src/components/AIChatBot.jsx`
- `public/profile.jpg`
- `public/resume.pdf`
- `public/assets/*.gif`

Then run:

npm install
npm run dev
